# Changelog — v0.x

## [0.1.0] — 2026/02/22

Initial release.

### Added

- Connection: `mysql_connect`, `mysql_close`, `mysql_status`.
- Options: `mysql_options_new`, `mysql_options_set_int`, `mysql_options_set_str`.
- Errors: `mysql_errno`.
- Unix socket support (auto-detected when `host` starts with `/`).
- TLS via rustls — no external runtime dependencies.
- Logger with banner; detailed log file at `logs/mysql.log`.
